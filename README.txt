مدرسة بهتيم الثانوية بنين — حزمة الموقع الكاملة

هذه الحزمة تشمل الموقع والدليل الدراسي والإنفوجرافيك مدمجًا بالفعل.

محتويات المجلد:
- index.html: الصفحة الرئيسية.
- guide.html: دليل المسارات والمواد والكليات، ويعرض الإنفوجرافيك.
- style.css و script.js: التنسيق والتفاعلات.
- assets/school-logo.svg: شعار المدرسة.
- assets/baccalaureate-pathways.png: إنفوجرافيك البكالوريا.

طريقة الرفع لأول مرة على GitHub:
1) فك ضغط ملف ZIP على جهازك.
2) افتح https://github.com وسجل الدخول.
3) اضغط علامة + أعلى الصفحة ثم New repository.
4) اكتب اسم المستودع مثل bahtim-school-website.
5) اختر Public، ثم اضغط Create repository.
6) داخل المستودع اضغط uploading an existing file أو Add file > Upload files.
7) افتح المجلد الذي فككت ضغطه، وحدد كل الملفات والمجلدات الموجودة داخله (index.html و guide.html و style.css و script.js و README.txt ومجلد assets).
8) اسحبها إلى صفحة GitHub. تأكد أن مجلد assets مرفوع وبداخله الصورتان.
9) اكتب رسالة مثل Initial website upload ثم اضغط Commit changes.
10) افتح Settings > Pages.
11) تحت Build and deployment اختر Deploy from a branch.
12) اختر main ثم /(root)، واضغط Save.
13) انتظر ظهور رابط الموقع في صفحة Pages وافتحه.

مهم:
- ارفع محتويات المجلد بعد فك الضغط، وليس ملف ZIP نفسه.
- لا ترفع ملفات المجلد الأب التي تحتوي المشروع داخل مجلد إضافي؛ يجب أن يكون index.html في جذر المستودع.
- الموقع ثابت ولا يحتاج npm أو قاعدة بيانات.
- قوائم الكليات إرشادية، والقبول النهائي حسب قواعد التنسيق الرسمية وشروط كل كلية في سنة التقديم.
